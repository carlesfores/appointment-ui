# Appointment UI

This repository uses Vite, React and Bulma.

- [React](https://reactjs.org): A JavaScript library for building user interfaces
- [Bulma](https://bulma.io): Free, open source css framework
- [Vite](https://vitejs.dev): Frontend tooling that provides faster and leaner development builds

## Getting Started

1. Clone the repository:
   ```bash
   git clone git@github.com:carlesfores/appointment-ui.git
   cd appointment-ui
   ```
2. Install the dependencies:

   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
